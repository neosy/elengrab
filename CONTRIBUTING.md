# Contributing to Elengrab

Thank you for your interest in Elengrab!

Elengrab is developed and maintained exclusively by its author. Community feedback, bug reports, and feature requests are welcome.

## Bug Reports

Before opening an Issue:
- Check that the problem has not already been reported.
- Use the latest version of Elengrab.
- Provide steps to reproduce the problem and relevant logs.

## Feature Requests

Feature requests are welcome. Describe the problem, the expected behavior, and the proposed improvement.

All suggestions are reviewed at the maintainer's discretion. There is no guarantee that they will be implemented.

## Code Contributions

Elengrab is maintained exclusively by its author. External code contributions, including Pull Requests and patches, are not accepted.

All development decisions, code changes, and releases are managed by the project maintainer.

Thank you for helping improve Elengrab!
